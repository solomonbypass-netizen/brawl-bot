# Документация Цикла 3: Генератор продающих постов для Telegram-каналов и Умный флип (Cycle 3)

## 1. Контекст и бизнес-цель
Основная бизнес-модель пользователя — **быстрый арбитраж (перепродажа аккаунтов Brawl Stars в Telegram-каналах с чистым профитом от +350 ₽ до +1200 ₽)**.
После решения проблемы быстрого отбора лотов (1-2 штуки за 1 секунду) главным узким местом оставался этап перепродажи:
- Пользователю приходилось вручную перепечатывать характеристики купленного аккаунта (кубки, бравлеры, прокачка 11 уровня, наличие OG-скинов).
- Тратить время на составление продающего текста, подбор привлекательных эмодзи, форматирование цен и указание реквизитов.
- Ручной выбор текста на мобильном телефоне приводил к ошибкам и потере времени.

## 2. Архитектурное решение

В рамках Цикла 3 разработана подсистема **One-Click Resale Generator**:

```
[ Карточка окупного лота на FunPay ]
                 │
                 ├── [ 🔗 Забрать на FunPay ] -> быстрая покупка
                 ├── [ 📸 Все фото (N) ]      -> медиа-группа в чат
                 └── [ 📢 Готовый пост в ТГ ]  -> генерация продающего поста
                                 │
                                 ▼
                     core/post_generator.py
                                 │
                                 ▼
          [ Сообщение с блоком <pre> (копирование в 1 клик) ]
          + Автоматическая подстановка контактов и цены
```

## 3. Внесенные изменения в кодовую базу

### 3.1. `core/post_generator.py` (Новый модуль)
- Формирует маркетинговый пост под формат Telegram-каналов:
  - 🏆 Кубки, бойцы, праймы 11 LVL.
  - 👑 Главные плюсы и скины (OG-раритеты, баланс гемов, Brawl Pass).
  - 🔒 Блок безопасности и гарантии (наличие родной почты Firstmail).
  - 💵 Оценочная стоимость в ТГ с заложенным профитом и завлекающими фразами.
  - 📩 Контакт продавца (индивидуальный юзернейм пользователя).
  - Хештеги `#brawlstars #аккаунты #продажа`.

### 3.2. `core/user_settings.py` (Расширение)
- Добавлено хранение персонального контакта продавца (`get_user_contact`, `set_user_contact`).
- Добавлена настройка фильтрации по бюджету (`get_user_budget`, `set_user_budget` — до 200 ₽, до 300 ₽, все до 420 ₽).
- Потокобезопасная запись через `threading.Lock()` в `user_settings.json`.

### 3.3. `core/bot_ui.py`
- В `make_lot_keyboard()` добавлена кнопка `📢 Готовый пост в ТГ`.
- В `get_settings_inline_keyboard()` добавлен второй ряд управления бюджетом покупки (`до 200 ₽`, `до 300 ₽`, `Все до 420 ₽`).

### 3.4. `main.py`
- Обработчик колбэка `post:<offer_id>`: извлекает характеристики из `offers_cache`, генерирует пост и отсылает его внутри HTML-тега `<pre>`, что позволяет скопировать весь текст одним касанием на смартфоне.
- Команда `/contact @username` для быстрого сохранения своего Telegram-тега.
- Фильтрация лотов по установленному бюджету пользователя перед показом.

## 4. Результаты тестирования и безопасность
1. **Защита от лимита подписей Telegram:** Пост отправляется отдельным сообщением, предотвращая ошибку `Bad Request: caption is too long (1024 chars)`.
2. **One-Tap Clipboard Copy:** Благодаря тегу `<pre>` пользователь на телефоне нажимает на текст один раз, и пост целиком копируется в буфер обмена.
3. **Безопасность кэша:** При клике на старые лоты проверяется наличие данных; при их отсутствии пользователь получает вежливый алерт без падения процесса.
