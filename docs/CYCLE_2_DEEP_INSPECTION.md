# Документация: Цикл 2 — Глубокий парсинг страницы оффера (Deep Offer Inspection)

## 1. Назначение
Цикл 2 устраняет зависимость бота от кратких строчек каталога. Модуль детальной инспекции автоматически обращается к странице оффера FunPay (`/lots/offer?id=...`) для кандидатов с высокой окупаемостью и обогащает карточку реальными визуальными и поведенческими данными.

## 2. Архитектура решения
```
[Каталог FunPay] ──► [Фильтр ликвидности] ──► [Топ-кандидат]
                                                    │
                                                    ▼
                                          deep_inspect_offer()
                                                    │
                     ┌──────────────────────────────┴──────────────────────────────┐
                     ▼                                                             ▼
           Скриншоты аккаунта                                              Онлайн-статус продавца
      (attachments-thumb -> sfunpay.com)                                (media-user-status)
                     │                                                             │
                     ▼                                                             ▼
         bot.send_photo() с fallback                                  🟢 Онлайн / 🟡 Недавно / 🔴 Офлайн
```

## 3. Защитные механизмы (Safety Constraints)
1. **Lazy Deep Inspection:** Запросы к странице оффера выполняются исключительно для отобранных лотов (3–5 шт.), а не для всего каталога из 4 000 строк. Это защищает IP сервера от лимитов Cloudflare / HTTP 429.
2. **Таймаут соединения:** Установлен лимит `timeout=6s` на запрос страницы оффера.
3. **Graceful Fallback доставки:** Если Telegram API не может скачать изображение с CDN FunPay (например, из-за блокировок IP или нестандартного формата), метод `send_lot_to_user` автоматически отправляет чистое текстовое HTML-сообщение без потери сделки.
4. **Инлайн-кнопка скриншотов:** В сообщение добавляется динамическая кнопка `[🖼️ Скриншоты (N)]` с прямой ссылкой на первый скриншот в полном разрешении.
