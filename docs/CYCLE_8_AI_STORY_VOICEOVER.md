# Цикл 8: Студия генерации вирусных AI-Shorts с озвучкой и драматургией

## 1. Контекст и Проблема
Предыдущая базовая генерация видео представляла собой простое переключение статических слайдов без озвучки и инфоповода («слайд-шоу уровня 2019 года»). Пользователь справедливо указал, что такой контент не привлечет органический трафик из TikTok, YouTube Shorts и VK Клипы.

Требовалось:
1. Создать отдельного специализированного субагента-продюсера (`creative_video_director`), отвечающего за идеи, инфоповоды, хуки и режиссуру монтажа.
2. Внедрить 4 вирусных архетипа историй (драматургия, кликбейтные хуки первых секунд, удержание внимания).
3. Интегрировать нейросетевую русскую озвучку (`ru-RU-DmitryNeural`) без сторонних платных API ключей.
4. Синхронизировать видеоряд 9:16 со звуковой дорожкой, добавить неоновые обводки, акцентные плашки и избавить рендер от битых шрифтов и квадратных глифов (`[]`).

---

## 2. Архитектура решения

### А. Субагент: 🎬 Креативный Продюсер (`creative_video_director`)
- Отвечает за разработку кликбейтных сценариев под каждый конкретный аккаунт на основе его характеристик (количество кубков, олд-скины, праймы 11 лвл, цена).
- Формирует скрипт закадрового голоса с триггерами срочности («успевай забрать», «в 3 часа ночи», «родители продают за двойку»).

### Б. Модуль драматургии: `core/story_director.py`
Генерирует 4 вирусных архетипа:
1. **«Нашел в 3 часа ночи за копейки...»** — триггер на редкие олд-скины (Шелли, Рикошет, Кольт, 2018/2019 г.).
2. **«Родители сливают акк за двойку!»** — эмоциональная драма для жирных аккаунтов от 25,000+ кубков.
3. **«Владелец даже не знал цену...»** — эффект невероятной халявы для прокачанных аккаунтов с 10+ праймами 11 уровня.
4. **«Купил самый дешевый аккаунт на бирже!»** — скоростной антикризисный флип с гарантией и родной почтой.

### В. Модуль нейро-озвучки: `core/voice_maker.py`
- Использует библиотеку `edge-tts` с высококачественным дикторским голосом `ru-RU-DmitryNeural`.
- Генерация MP3 файла длится ~1.2-1.6 секунды.
- Работает полностью автономно на сервере без необходимости указывать API-ключи.

### Г. Мультиплексирование и монтаж: `core/video_maker.py`
- Полноценный 9:16 холст (720x1280) с блюр-подложкой и золотой рамкой карточки аккаунта.
- Автоматическая очистка текста от эмодзи (`strip_emojis`) для исключения квадратов `[]` при рендере системными шрифтами.
- Сведение дорожек в FFmpeg: объединение 3 вертикальных видеосцен и аудиодорожки с флагом `-shortest` и ультрабыстрым кодированием `libx264` / `aac`.
