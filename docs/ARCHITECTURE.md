# Архитектура проекта: FunPay Brawl Stars Arbitrage Scanner

## 1. Обзор системы
Проект представляет собой автоматизированный брокерско-аналитический комплекс для обнаружения недооцененных игровых активов на торговой площадке FunPay, их скоринга по факторам ликвидности и мгновенного оповещения через Telegram.

## 2. Структура модулей
```
sharp-faraday/
├── core/
│   ├── config.py         # Переменные окружения, токены, URL, интервалы
│   ├── analyzer.py       # Парсинг цен (data-s), анти-спам, гемы, ликвидность
│   ├── scanner.py        # HTTP-запросы к каталогу FunPay, BeautifulSoup, кэш seen_offers
│   ├── server.py         # Легковесный HTTP-сервер для health-checks на Render (Free Tier)
│   └── bot_ui.py         # Шаблоны сообщений, плашки надежности, клавиатуры
├── docs/
│   └── ARCHITECTURE.md   # Документация системы
├── main.py               # Главный оркестратор (запуск потоков сервера, сканера, бота)
├── funpay_brawl_bot.py   # Точка входа для обратной совместимости с Render
├── requirements.txt      # Зависимости проекта
└── Procfile              # Конфигурация запуска в облаке
```

## 3. Критерии ликвидности (Market Triggers)
Аккаунт признается окупным только при соблюдении следующих условий:
1. **Ценовой диапазон:** 100 – 420 ₽ (минимальный порог риска и максимальная скорость перепродажи).
2. **Триггеры спроса:**
   - Наличие редких архивных скинов (2018–2020: Звездная Шелли, Корсар Кольт, Рикошет, Вирус 8-Бит).
   - Подтвержденный положительный баланс гемов (от 70 до 500 гемов на балансе).
   - Купленный активный Brawl Pass+.
   - Полная коллекция бравлеров (78+) или 14+ максимально прокачанных бойцов (11 LVL).
3. **Безопасность:**
   - Жесткая блокировка спам-лотов и лотов с отрицательными гемами (рефанд-бан).
   - Оценка надежности продавца (Trust Score).

## 4. Потокобезопасность
Доступ к файлу кэша `seen_offers.json` защищен примитивом синхронизации `threading.Lock()`, предотвращая повреждение JSON при одновременном обращении фонового демона и обработчиков команд Telegram.
