# Remotion Brawl Stars Promo Video (Apple / Linear Aesthetic)

Профессиональное вертикальное промо-видео (1080x1920, 30 fps, 12 секунд / 360 кадров) для продвижения Telegram-канала с продажей аккаунтов Brawl Stars.

## 🎨 Дизайн и Эстетика (Apple / Linear Style)
- **Цветовая палитра:** Глубокий темный фон `#09090b` (`bg-zinc-950`) с акцентными неоновыми свечениями Indigo (`#6366f1`) и Violet (`#8b5cf6`).
- **Сетка и глубина:** Тонкая геометрическая сетка в стиле Linear (`rgba(255, 255, 255, 0.035)`) с радиальным размытием и виньеткой.
- **Типографика:** Шрифт Inter / Geist, `font-extrabold` (900), легкое двойное свечение, кинетическое появление по 1-3 слова.
- **Физика анимации:** Remotion `spring({ damping: 14, stiffness: 120 })` — премиальный пружинный отклик без рывков.
- **Аудиомикширование:** 
  - Дикторский голос (`audio/voice.mp3`): громкость `1.0` (чистый, громкий, спереди).
  - Фоновый синематик-бит (`audio/background-music.mp3`): приглушен на `0.18`, с плавным затуханием в конце.

## ⏱ Тайминг сцен (Ровно 12 секунд / 360 кадров)

1. **0–3 сек (Кадры 0–90) — ХУК / Инфоповод:**
   - Бейдж: `⚡ ИНСАЙД РЫНКА`
   - Слова поочередно: `BRAWL STARS` -> `УХОДИТ?` -> `ИЛИ АККАУНТЫ ОБЕСЦЕНИЛИСЬ?`
   - Голос: *"Бравл Старс уходит? Или аккаунты просто обесценились?"*

2. **3–6 сек (Кадры 90–180) — БОЛЬ / КЛИКБЕЙТ:**
   - Бейдж: `⚠️ ОФИЦИАЛЬНЫЙ ШОП`
   - Текст: `РАЗРАБОТЧИКИ ЗАКРУЧИВАЮТ ГАЙКИ` -> `ЦЕНЫ ВЗЛЕТЕЛИ В 3 РАЗА!`
   - Голос: *"Разработчики жестко закручивают гайки, а цены в официальном магазине взлетели в три раза."*

3. **6–9 сек (Кадры 180–270) — РЕШЕНИЕ / ДЕФИЦИТ:**
   - Премиальная стеклянная карточка лота: `50,000+ кубков`, `Все легендарки`.
   - Падение ценника: зачеркнутые `5 000 ₽` -> пружинный дроп до `490 ₽`.
   - Текст: `УМНЫЕ ИГРОКИ СКУПАЮТ ЗА КОПЕЙКИ`
   - Голос: *"Пока лазейку не закрыли, умные игроки скупают приватные аккаунты за копейки."*

4. **9–12 сек (Кадры 270–360) — CALL TO ACTION:**
   - Неоновый пульсирующий QR-код.
   - Плашка канала: `@solomon` с иконкой самолета.
   - Бейдж дефицита: `🔥 ОСТАЛОСЬ ВСЕГО 3 МЕСТА`.
   - Стрелка: `ССЫЛКА В ШАПКЕ ПРОФИЛЯ ↗`
   - Голос: *"Твой забирай по ссылке в шапке профиля или ищи канал solomon. Осталось всего три места."*

## 🚀 Запуск и Рендеринг

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Интерактивный просмотр (Remotion Studio):
```bash
npm start
```
Откроется браузерная студия Remotion (`localhost:3000`), где можно покадрово просматривать анимации, двигать ползунок и менять props.

### 3. Рендеринг финального MP4 видео:
```bash
npm run build
```
Итоговый ролик отрендерится в `out/video.mp4` в идеальном качестве 1080x1920 (вертикальный 9:16).
